Sistema completo de gestão de funcionários, com backend em Spring Boot, frontend em React e microserviço de relatórios em Python.

GestFun — Sistema de Gestão de Funcionários
GestFun é um sistema modular e escalável para gestão de funcionários, departamentos e relatórios, desenvolvido com uma arquitetura moderna composta por:

Backend (Spring Boot)

Frontend (React)

O objetivo é fornecer uma solução rápida, organizada e multiplataforma, preparada para Web, Desktop e Mobile.

🚀 Tecnologias Utilizadas
Backend — Spring Boot
Java 17

Spring Boot

Spring Data JPA

Hibernate

Maven

MySQL

Frontend — React
React + Vite + Tailwind CSS

Axios

React Router

CSS Modules / Tailwind (dependendo da tua config)

🧱 Arquitetura do Projeto
Código
GestFun/
 ├── backend/          # API REST em Spring Boot
 ├── frontend/         # Interface web em React
🛠️ Como Rodar o Projeto
🔹 1. Backend (Spring Boot)
bash
cd backend
mvn spring-boot:run
A API ficará disponível em:

Código
http://localhost:8080
🔹 2. Frontend (React)
bash
cd frontend
npm install
npm run dev
Interface disponível em:

Código
http://localhost:5173
